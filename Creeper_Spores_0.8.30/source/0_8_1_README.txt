CREEPER SPORES 0.8.1 — FIELD STORY UPDATE
Minecraft Bedrock Edition only. Experimental. Built from 0.8.0 source.

WHAT CHANGED IN 0.8.1
- Added a saved, player-private branching Field Story to the Spore Research Journal.
- Chapter progress uses existing saved research events: first sample, three strains, and first hatch.
- Players choose a Garden Path or Ruin Path. The choice persists per player.
- Garden Path finale requires 12 hybrid harvests. Ruin Path finale requires two nests and one connected-colony survey.
- XP is awarded only after chapter progress is successfully saved. Reopening the journal cannot pay the same chapter twice.
- Existing colony networks, three hybrid plants, 23 environmental profiles, 23 ambient animations, air/water spread, item visuals, and optional micro-ruins remain from 0.8.0.
- New world-mutating features remain individually OFF by default. No identifiers or original creeper artwork were intentionally changed.

INSTALLATION
Import Creeper_Spores_0.8.1_Expanded.mcaddon, then enable both Creeper Spores packs in a disposable test world or a backed-up world. The core pack requires Bedrock 1.21.130 or later and Script API beta support. The optional native world-generation pack is separate and is not part of the default add-on.

VERIFICATION
The package includes offline source checks for JSON parsing, JavaScript syntax and imports, manifests, texture links, item recipe outputs, new 0.8 systems, and Field Story wiring. Offline checks do not prove Bedrock runtime compatibility. In-game testing status is reported separately.

STILL INCOMPLETE OR UNVERIFIED
- Full unique combat, targeting, movement and explosion AI for all 23 creepers.
- Complete water/lava/phantom navigation, actual wind and current physics, and all transmission edge cases.
- World-spanning synchronized colony networks; current networks are local and loaded-area only.
- Full crop ecology, withering, suppression, cross-pollination, and species-specific mob reactions.
- Vanilla villager profession trades; the separate research trader remains.
- Full structure templates, bespoke encounters and guaranteed world generation across agreed biomes; the new systems are scripted micro-ruins plus an optional unverified feature-rule pack.
- A drawn persistent atlas, branching dialogue, full narrative world, and all originally requested progression. 0.8.1 adds one saved two-path research story, not a complete quest campaign.
- Industrial redstone factories, physical opening pod geometry, unique hatch scenes, finished armor models, and final lantern/torch/ornamental-block models.
- Reliable protection for blocks placed before this update or by commands/add-ons.
- Every item, recipe, API call, animation, model, world migration, multiplayer race, mobile/controller/server session and performance case must still be verified in Bedrock.
- Earlier conflicting exact biome and growth values remain neutral instead of inventing preferences.
